# Arabic-first, RTL by default

Arabic is the app's primary language and its default layout direction is right-to-left. English is the second language. Arabic comes first because the maintainer and the primary audience are Arabic speakers, so Arabic copy, RTL layout and Arabic typography are designed first rather than retrofitted onto an English design.

## Consequences

Every screen and Widget Variant is designed and reviewed in Arabic/RTL first, then checked in English/LTR. Strings are written in Arabic first and then translated. Fonts, digit style (Eastern Arabic vs Western) and Hijri date formatting are first-class concerns, not localisation afterthoughts.
